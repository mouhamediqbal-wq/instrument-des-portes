# Les cavités (3ᵉ fondement) — prédiction préenregistrée (13/10/2026, 13h58, Paris) — écrite AVANT calcul
Instrument : axe courbé θ(t) + deux fentes égales + premiers montés en cavités de Fabry-Pérot. Note = changement de signe de
  Z_cav(t) = Re[ e^{iθ(t)} ∏_{p ≤ X} (1 − p^{−1/2 − it})^{−1} ] / |∏| = cos(θ(t) + arg ∏).
Le facteur (1 − p^{−s})^{−1} = 1 + p^{−s} + p^{−2s} + … est l'écho infini (tous les m) ; le produit contient automatiquement la corde 1.
Variantes (même mesure que le démontage : appariés à moins de 0,1 écart local ; 1 004 zéros ; 10 ≤ t ≤ 1 430) :
T5a : cavités, X = √(t/2π) (le nombre de cordes croît avec la hauteur, comme Riemann-Siegel).
T5b : cordes simples (m = 1 seulement, pas d'écho), X = √(t/2π) — même jeu de premiers que T5a.
T5c : cavités, X = 1 000 fixe (beaucoup de premiers, pas de croissance).
Prédictions de Claude :
C1 : T5a > T3b (42,6 %) — la cavité fait une partie du travail des composés — et T5a < 100 %.
C2 : T5a > T5b (l'écho compte).
C3 : T5a entre 50 % et 90 %.
C4 : T5c > T5a (plus de premiers aide, même sans la règle de croissance).
