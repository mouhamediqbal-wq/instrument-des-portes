# Le chanfrein (adoucir le bord des cavités) — prédiction préenregistrée (13/10/2026, 14h15, Paris) — écrite AVANT calcul
Base : instrument d'horloger, coupure nette, tous les échos m, premiers p ≤ X = t/2π (fenêtres V1-V4 de l'étape 3 : 98,9 / 99,5 / 100 / 97,5 %).
Chaque écho n = p^m reçoit un poids W(ln n / ln X) dans la phase Σ Im(p^{−m(1/2+it)})/m :
- Coupure nette (référence) : W = 1 si ln n ≤ ln X, 0 sinon.
- Va, chanfrein de Selberg : W(u) = 1 − u pour u ≤ 1, 0 au-delà (adoucit en retirant de la force aux grands premiers, même X).
- Vb, chanfrein extérieur : W = 1 jusqu'à u = 1, puis descente en demi-cosinus jusqu'à 0 en ln n = ln(2X) (le trou garde toute sa taille, seul le bord est arrondi, au-delà de X).
Mesure : appariés (< 0,1 écart local) et écart moyen, mêmes vrais zéros.
Prédictions de Claude :
Ch1 : Va fait MOINS bien que la coupure nette (il retire trop de force).
Ch2 : Vb atteint ≥ 99 % dans les quatre fenêtres.
Ch3 : Vb réduit l'écart moyen dans les quatre fenêtres par rapport à la coupure nette.
