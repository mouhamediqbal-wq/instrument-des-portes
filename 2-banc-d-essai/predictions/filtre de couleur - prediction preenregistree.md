# Le filtre de couleur (plaque de Dirichlet mod 4) — prédiction préenregistrée (13/10/2026, 15h45, Paris) — écrite AVANT calcul
Plaques : portes de ζ (zéros γ ≤ 320, pris parmi les 1 004 connus) et portes de L(s, χ₄) (220 zéros ≤ 320, calculés ; premier 6,0209). Même ouverture cos²(πγ/2T), T = 320.
R_ζ(x) ≈ Λ(x) ; R_χ(x) = −(4π/T)√x Σ w cos(γ ln x) ≈ χ₄(x)Λ(x).
Filtres : « bleu » = (R_ζ + R_χ)/2 ≈ Λ(x) si x ≡ 1 (mod 4), 0 sinon ; « rouge » = (R_ζ − R_χ)/2 ≈ Λ(x) si x ≡ 3 (mod 4), 0 sinon ; 2 et ses puissances : ½ ln 2 dans les deux.
Prédictions (entiers impairs 3 … 45, seuil 0,4 ; puissances de 2 exclues) :
F1 : le filtre bleu laisse passer exactement les puissances de premiers ≡ 1 (mod 4) : 5, 9, 13, 17, 25, 29, 37, 41 (9 = 3² et 25 = 5² : χ₄ = +1) ; il bloque 3, 7, 11, 19, 23, 27, 31, 43 et tous les composés.
F2 : le filtre rouge laisse passer exactement 3, 7, 11, 19, 23, 27, 31, 43 (27 = 3³ : χ₄ = −1) et bloque le reste.
F3 : au moins 95 % de bons classements sur l'ensemble (2 filtres × 22 impairs).
