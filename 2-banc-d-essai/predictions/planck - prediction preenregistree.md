# La constante de Planck des premiers — prédiction préenregistrée (13/10/2026, 15h58, Paris) — écrite AVANT calcul
Modèle (Berry-Keating) : flot H = xp ; région {x ≥ ℓx, p ≥ ℓp, xp ≤ E} avec ℓx·ℓp = h = 2π (ħ = 1) ; surface A(E) = E ln(E/2π) − E + 2π ; nombre de cases de Planck A/h ; avec la correction de point zéro −1/8 : N_cases(E) = (E/2π)(ln(E/2π) − 1) + 7/8.
Vérification « une porte par case » :
P1 (les 1 004 premières portes) : écart S_n = (n − ½) − N_cases(γ_n) : |moyenne| < 0,05 ; écart-type entre 0,15 et 0,45 ; max |S_n| < 1,5.
P2 (fenêtres en hauteur déjà calculées par Riemann-Siegel : W4 ≈ 10⁴, V2 ≈ 3·10⁴, H1 ≈ 10⁵, V3 ≈ 3·10⁵, H2 ≈ 10⁶, V4 ≈ 2·10⁶) : |nombre de portes − nombre de cases (θ(b) − θ(a))/π| ≤ 2 dans chaque fenêtre.
P3 : sur l'ensemble des six fenêtres, portes / cases = 1 à 0,5 % près.
P4 (la constante elle-même) : si l'on remplace h = 2π par h' dans le compte des cases, le meilleur accord avec les 1 004 portes (moindres carrés sur S_n) est obtenu pour h' = 2π à 1 % près.
